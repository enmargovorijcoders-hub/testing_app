# Device Test

A tiny Android app (no libraries) that tests the hardware on a phone: cameras and flash, microphone,
speaker, vibration, touch screen, display, sensors, GPS, SIM / eSIM / VoLTE info, Wi-Fi, Bluetooth, NFC,
battery and buttons. Android 4.0+ (API 14), ARM and ARM64.

Build: upload everything in this folder to a GitHub repository (branch `main`), open the Actions tab,
and download the `DeviceTest-apk` artifact when the run is green.
